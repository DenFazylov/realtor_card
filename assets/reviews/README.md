# Отзывы

Добавляйте изображения отзывов последовательно:

- `1.jpg`
- `2.jpg`
- `3.jpg`
- и т. д.

Поддерживаются расширения `.jpg`, `.jpeg`, `.png`, `.webp`.

Нумерация должна идти без пропусков. Блок отзывов автоматически скрыт, пока `1` отсутствует, и автоматически появляется после добавления изображений.
