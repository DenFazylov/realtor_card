# Отзывы

Добавляйте изображения отзывов последовательно:

- `review-1.jpg`
- `review-2.jpg`
- `review-3.jpg`
- и т. д.

Поддерживаются расширения `.jpg`, `.jpeg`, `.png`, `.webp`.

Нумерация должна идти без пропусков. Блок отзывов автоматически скрыт, пока `review-1` отсутствует, и автоматически появляется после добавления изображений.
